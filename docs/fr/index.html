Foire Aux Questions

Questions Fréquentes sur flow-video-merger

Toutes les réponses pour maîtriser l'assemblage de vos vidéos Google Flow.

Qu'est-ce que flow-video-merger ?
flow-video-merger est une extension Chrome open-source (Manifest V3) et un banc de montage Studio Web plein écran spécialement conçus pour Google Flow (flow.google) et Google Veo / Veo 2. Elle capture vos générations, identifie les versions surclassées 4K /boost, ordonne les plans de façon dramatique et fusionne vos scènes en un film 4K fluide avec audio.
Où trouver et télécharger le code source sur GitHub ?
Le projet est 100% gratuit et libre sous licence MIT sur GitHub : https://github.com/leonbathie/flow-video-merger. Vous pouvez télécharger le ZIP directement, mettre une étoile au dépôt ou contribuer.
Comment l'extension résout-elle les erreurs de lecture Google Cloud ?
Les buckets de stockage vidéo de Google appliquent une règle stricte de blocage Cross-Origin Read Blocking (CORP), provoquant souvent l'erreur net::ERR_BLOCKED_BY_RESPONSE.NotSameSite. flow-video-merger embarque des règles declarativeNetRequest (rules.json) qui ajustent de manière sécurisée les en-têtes réseau pour permettre la lecture fluide dans Chrome.
Comment fonctionne la mise à niveau automatique 4K /boost ?
Dès que vous effectuez un agrandissement 4K sur Google Flow, Google enregistre un fichier vidéo haute définition dans un chemin de stockage /boost. flow-video-merger détecte cette URL et remplace le brouillon basse résolution par le fichier 4K d'origine tout en conservant l'ordre de vos clips.
Mes créations et vidéos sont-elles envoyées sur un serveur ?
Jamais. Tout se déroule à 100 % sur votre ordinateur dans votre navigateur Chrome. Aucune télémétrie, aucun traqueur, aucune base de données externe et aucun compte requis.
